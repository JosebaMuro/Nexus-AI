Agente IA 4.2.0 - instaladores (todos 100 % portables: se instalan sin internet)
==================================================================================

Todos llevan dentro Python, las dependencias y los motores de IA de su plataforma (ONNX Runtime GenAI, OpenVINO
GenAI, LiteRT-LM, ExecuTorch, Genie en Snapdragon y llama.cpp de respaldo). Al arrancar, Agente IA detecta el hardware
(procesador, grafica, NPU y memoria), activa los motores que funcionan en ese equipo y elige el modelo de IA adecuado;
lo descarga si hay internet (sin internet lo recomienda y se descarga despues desde la app).
Todos pueden dejar Agente IA como servicio que arranca solo con el equipo.
Los ficheros conservan el nombre anterior del proyecto (Nexus-Office).

windows/  Nexus-Office-Setup-4.2.0-windows-x64.exe    PC con Windows 10/11 de 64 bits (Intel/AMD; NVIDIA con CUDA)
          Nexus-Office-Setup-4.2.0-windows-arm64.exe  Windows 11 en ARM (Snapdragon X)
          Doble clic; si Windows avisa "protegio su PC": Mas informacion > Ejecutar de todas formas.
          Silencioso: Nexus-Office-Setup-...exe /S /OFICINA=herreria /SERVICIO /RED
linux/    sh Nexus-Office-4.2.0-linux-x86_64.run [carpeta] [--oficina=herreria] [--servicio] [--red]
          sh Nexus-Office-4.2.0-linux-aarch64.run      ARM de 64 bits: Raspberry Pi 4/5 (Raspberry Pi OS 64 bits),
                                                     Jetson, portatiles ARM
          sudo apt install ./nexus-office_4.2.0_amd64.deb   (o _arm64.deb en Raspberry Pi OS 64 bits / ARM)
          luego: nexus-office   |   servicio: sudo nexus-office servicio instalar [--red]
          Nexus-Office-4.2.0-linux-x86_64.AppImage / -aarch64.AppImage   sin instalar: chmod +x y abrir
          flatpak install --user Nexus-Office-4.2.0-linux-x86_64.flatpak  (o -aarch64; pide el runtime de Flathub)
macos/    Nexus-Office-4.2.0-macos-arm64.tar.gz (Apple Silicon) / macos-x86_64 (Intel): descomprimir y abrir
          "Nexus-Office.command" (o ./install.sh --oficina=herreria --servicio && ./start.sh)
android/  Nexus-Office-4.2.0-android-autonomo.apk  Agente IA completo dentro del movil (ARM64, Android 9+), sin PC;
                                                  usa la NPU (Snapdragon, Tensor, Dimensity) o la GPU si acelera
          Nexus-Office-4.2.0-android-vpn.apk       app ligera que conecta con el Agente IA de la oficina (VPN o Wi-Fi)
ubuntu/   rehacer-ubuntu.sh   rehace la ISO de Ubuntu Server para que la instalacion minima lleve Agente IA (u otro
          proyecto Python) preinstalado como servicio activo y preconfigurado:
          sudo ./rehacer-ubuntu.sh --descargar 24.04 --deb nexus-office_4.2.0_amd64.deb --probar
Nexus-Office-4.2.0-codigo-fuente.zip               proyecto limpio (codigo, pruebas, empaquetado y documentacion)
Manual-de-usuario.pdf / Documentacion-tecnica.pdf

Oficina: 58 perfiles de pyme por gremio; tras instalar, la vista Modelos sugiere modelos especificos del sector.
Raspberry Pi: hace falta el sistema de 64 bits (Raspberry Pi OS 64-bit, Ubuntu); Pi 4 o Pi 5 con 4 GB o mas.
Integridad: SHA256SUMS.txt
Agente-IA-cpp-referencia-codigo-fuente.zip   codigo de la edicion C++ 3.x retirada del repositorio (59fa50d)
