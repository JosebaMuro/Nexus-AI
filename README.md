# Nexus-Office 1.7.0

Oficina para pymes con agentes por gremio (antes se llamaba NEXUS AI; ahora tiene nombre propio para no confundirla con la IA particular NexusAI, y las dos pueden instalarse en el mismo equipo). Instaladores 100 % portables (se instalan sin internet) para Windows, Linux (x86_64 y ARM64/Raspberry Pi), macOS y Android.

**Descargas:** https://josebamuro.github.io/Nexus-AI/ · [Release v1.7.0](https://github.com/JosebaMuro/Nexus-AI/releases/tag/v1.7.0)

Instrucciones por plataforma en [LEEME.txt](LEEME.txt); integridad en [SHA256SUMS.txt](SHA256SUMS.txt). La versión anterior, con el nombre NEXUS AI, sigue en la [Release v1.6.0](https://github.com/JosebaMuro/Nexus-AI/releases/tag/v1.6.0).
