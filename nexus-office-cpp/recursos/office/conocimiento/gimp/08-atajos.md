# Manual de GIMP 8. Atajos de teclado (por defecto en GIMP 2.10 y 3)

Se pueden cambiar en Editar > Atajos de teclado. En macOS, Ctrl es Cmd.

| B | Rutas | T | Texto |

| Mayús+R | Rotar | Mayús+S | Escalar |

| P | Pincel | N | Lápiz |

## Ficheros y edición
| Atajo | Acción |
|---|---|
| Ctrl+N / Ctrl+O | Nueva imagen / Abrir |
| Ctrl+Alt+O | Abrir como capas |
| Ctrl+S / Mayús+Ctrl+S | Guardar XCF / Guardar como |
| Mayús+Ctrl+E / Ctrl+E | Exportar como / Exportar de nuevo |
| Ctrl+Z / Ctrl+Y | Deshacer / Rehacer |
| Ctrl+C / Ctrl+X / Ctrl+V | Copiar / Cortar / Pegar |
| Mayús+Ctrl+C | Copiar lo visible (todas las capas) |
| Mayús+Ctrl+V | Pegar como imagen nueva |
| Ctrl+, / Ctrl+. | Rellenar con el color de frente / de fondo |
| Supr | Borrar el contenido de la selección |
| Ctrl+D | Duplicar la imagen |
| / | Buscar y ejecutar cualquier orden por su nombre |

|---|---|

| Ctrl+I | Invertir la selección |
| Mayús+Q | Máscara rápida |
| Mayús+V | Ruta a selección |
| Mayús+Ctrl+N | Capa nueva |
| Mayús+Ctrl+D | Duplicar capa |
| Ctrl+H | Anclar la capa flotante |
| Re Pág / Av Pág | Capa superior / inferior como activa |

| 1 / Mayús+Ctrl+J | Ver al 100 % / ajustar a la ventana |

| Espacio + arrastrar | Desplazar la vista |
| F11 | Pantalla completa |

## Modificadores al dibujar o seleccionar
- Mayús+clic con una herramienta de pintura: línea recta desde el último punto. Ctrl+Mayús: ángulos de 15°.
- Ctrl+clic con Clonar o Saneado: fija el origen.
- Al seleccionar: Mayús añade, Ctrl resta; pulsadas después de empezar a arrastrar, Mayús mantiene la proporción y
  Ctrl dibuja desde el centro.
- Alt+clic sobre una miniatura de máscara: ver la máscara sola.
